# HEAD LASER: DOG INVASION

¡Un mini-juego arcade 2D retro renderizado 100% mediante código y primitivas! Desarrollado con Python, `pygame-ce` y empaquetado para la web con `pygbag`.

## Características
- Estilo visual de terminal antigua/fósforo verde (CRT opcional).
- Generación de sonidos sintetizados al vuelo usando `numpy` (sin archivos de audio externos).
- Arte 100% generado por código con Pygame (sin archivos PNG externos).
- Compatible para jugar en escritorio y nativamente en el navegador.
